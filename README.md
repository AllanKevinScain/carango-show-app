# 🎓 Projeto React Vite com TypeScript e Axios (FACCAT)

Este repositório contém um projeto desenvolvido em **React** com **Vite** utilizando **TypeScript** e **Axios**.  
O objetivo é servir como trabalho acadêmico para a **FACCAT**, demonstrando boas práticas de desenvolvimento web moderno, consumo de APIs e organização de código.

---

## 🚀 Tecnologias Utilizadas

- **[React](https://reactjs.org/)** – Biblioteca para construção de interfaces.
- **[Vite](https://vitejs.dev/)** – Ferramenta de build rápida e moderna.
- **[TypeScript](https://www.typescriptlang.org/)** – Superset do JavaScript com tipagem estática.
- **[Axios](https://axios-http.com/)** – Cliente HTTP para consumo de APIs REST.
- **[ESLint](https://eslint.org/)** + **[Prettier](https://prettier.io/)** – Padronização e qualidade de código.

---

## 📂 Estrutura do Projeto

```bash
├── src
│   ├── api        # Configurações e chamadas de API com Axios
│   ├── components # Componentes reutilizáveis
│   ├── pages      # Páginas principais do sistema
│   ├── hooks      # Hooks customizados
│   ├── styles     # Estilos globais (CSS/Tailwind)
│   ├── App.tsx    # Componente raiz
│   └── main.tsx   # Ponto de entrada da aplicação
├── tsconfig.json  # Configuração do TypeScript
├── vite.config.ts # Configuração do Vite
└── package.json
```
